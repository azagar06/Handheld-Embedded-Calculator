# SOLIDWORKS Source Files

The `calctop.SLDPRT` file is stored as a GitHub Release asset because GitHub's browser uploader rejected it from the main repository.

To open the complete assembly:

1. Open the repository's **Releases** section.
2. Download `calctop.SLDPRT` from the release assets.
3. Place it in the same local folder as `Calculator.SLDASM` and `calcbase.SLDPRT`.
4. Open `Calculator.SLDASM` in SOLIDWORKS.

The printable version of the part is available at `mechanical/stl/calctop.STL`.
